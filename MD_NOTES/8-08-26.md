# Django – Add Restaurant Page

## 1. URL Configuration
- Created a URL path for the **Add Restaurant** page in `urls.py`.
- Connected the URL to the `open_add_restaurant()` view.
- This tells Django which view should execute when the URL is accessed.

**Flow:**  
URL → View → HTML Template

---

## 2. View Creation
- Created the `open_add_restaurant()` function in `views.py`.
- Used Django's `render()` function to display the Add Restaurant HTML page.
- The view connects the URL with the HTML template.

---

## 3. Admin Home Navigation
- Added an **ADD NEW RESTAURANT** link in `admin_home.html`.
- When the admin clicks the link, the browser requests the Add Restaurant URL.
- Django finds the URL and calls the corresponding view.

**Flow:**  
Admin Home → Click Link → URL → View → Add Restaurant Page

---

## 4. Add Restaurant Form
- Created a form to collect restaurant details.
- Added fields for:
  - Restaurant Name
  - Picture URL
  - Cuisine
  - Rating
- Used the **POST** method because the form will send data to the Django server.

---

## 5. Input `name` Attributes
- Each input field was given a `name` attribute.
- Django uses these names to identify and retrieve the submitted values from `request.POST`.
- This allows the backend to access each form value separately.

---

## 6. Rating Validation
- Used a number input for the restaurant rating.
- Restricted the rating between **0 and 5**.
- Used `step="0.5"` so ratings can be entered in increments of 0.5.

**Example:**  
0 → 0.5 → 1 → 1.5 → ... → 5

---

## 7. CSRF Protection
- Added Django's **CSRF token** inside the POST form.
- CSRF protection prevents unauthorized websites from submitting requests to our application on behalf of the user.

---

# Django – Update Restaurant Functionality

## 1. Passed Restaurant ID from Restaurant List

- Added an **Update Restaurant Info** link for each restaurant in the restaurant table.
- Passed the selected restaurant's `id` through the URL.
- This is necessary because Django needs to know **which restaurant** the admin wants to update.

**Flow:**

Restaurant List → Click Update → Send Restaurant ID → Update Page

---

## 2. Created Dynamic URL with Restaurant ID

- Created URL patterns that accept a restaurant ID.
- Used Django's `<int:restaurant_id>` URL parameter.
- `int` ensures that the value received in the URL is an integer.
- Used `restaurant_id` consistently in both the URL and view.

**Why?**

Without the ID, Django wouldn't know which restaurant record should be opened or updated.

---

## 3. Created `open_update_restaurant()` View

- Created a view to open the update page for the selected restaurant.
- Received the `restaurant_id` from the URL.
- Used the ID to retrieve the corresponding restaurant from the database.
- Passed the restaurant object to `update_restaurant.html`.

**Flow:**

Restaurant ID → Fetch Restaurant → Send Restaurant to Update Template

---

## 4. Pre-Filled the Update Form

- Displayed the existing restaurant information inside the update form.
- The form shows the current:
  - Restaurant name
  - Picture URL
  - Cuisine
  - Rating
- This allows the admin to modify existing information instead of entering everything again.

---

## 5. Created Update Form Submission

- The update form sends the modified data using a **POST request**.
- The restaurant ID is included in the form action URL.
- Added CSRF protection to secure the POST request.

**Flow:**

Update Form → POST Request → `update_restaurant()` View

---

## 6. Created `update_restaurant()` View

- Created a view to process the updated restaurant information.
- Received the `restaurant_id` from the URL.
- Retrieved the existing restaurant using that ID.
- Checked whether the request method is `POST`.
- Retrieved the updated form values using `request.POST.get()`.

---

## 7. Updated Restaurant Record

- Replaced the old restaurant values with the new values submitted from the form.
- Used `restaurant.save()` to save the changes to the database.
- This updates the existing restaurant record instead of creating a new restaurant.

**Flow:**

Get Restaurant → Get Updated Data → Modify Object → `save()` → Database Updated

---

## 8. Displayed Updated Restaurant List

- After successfully updating the restaurant, fetched all restaurants again.
- Sent the updated `restaurantList` to `show_restaurants.html`.
- This allows the admin to immediately see the updated restaurant information.

---
