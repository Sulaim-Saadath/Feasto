# Feasto

Food Delivery Web Application built with Django — simple restaurant/menu management, customer sign-up/sign-in, cart/checkout flow with Razorpay integration.

## Quick summary
Feasto is a small Django-based food delivery/demo app that implements:
- Customer signup/signin and profile fields (username, password, email, mobile, address)
- Restaurant and menu item CRUD (add / update / delete restaurants and items)
- Cart management (add items to cart, view cart, calculate total)
- Checkout integration using Razorpay (server creates payment orders)
- Admin interface via Django admin

## Stack
- Language(s): Python, HTML, CSS
- Framework: Django 6.1 (project settings reference Django 6.1)
- Notable libraries: Razorpay (payments), Django ORM, built-in Django auth/admin
